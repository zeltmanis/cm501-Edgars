# EPA 2 starter kit: Campus Café menu and contact page

Two pages of the Campus Café "before" website as plain HTML + CSS, **built badly on purpose**.
Your job (individual): make them semantic and accessible (WCAG 2.2 AA). The task is in
`epa2-assessment-brief.pdf` on the course page.

| File | What it is |
|------|------------|
| `menu.html` | Menu page: start here in Session 3 |
| `contact.html` | Contact page with form: Session 4 (forms) |
| `before.css` | The styles. You may change them (contrast, focus), but layout/responsiveness is EPA 3 |
| `img/` | Images used by the pages |

View locally: open `menu.html` in the browser, or run `npx serve .` and open the URL it prints.

Do **not** use a framework or a site builder. Hand-written HTML and CSS only.
