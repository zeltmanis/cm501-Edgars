## VoiceOver keys used
| Action | Keys |
|---|---|
| Turn on/off | Cmd+F5 |
| Rotor (headings, landmarks, links lists) | VO+U, then Left/Right to switch list |
| Next heading | VO+Cmd+H |
| Read next item | VO+Right |
| Click / activate | VO+Space |

VO = Ctrl+Option.
