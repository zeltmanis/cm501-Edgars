Style guide: Mist

For recruiters, lecturers and classmates who want to know what I study and build: the site should feel calm, light and modern, like morning mist, with frosted-glass cards and one colourful highlight.

All values live once in :root of styles.css. This page links the same file, so what you see here is what the site uses.

Colours

Tokens are named by role, not by colour. Contrast measured with the WCAG formula (checked in the DevTools colour picker): text needs 4.5 : 1, large text and UI parts 3 : 1.

  • --color-text
    #111215 · body text
    16.5 : 1 on bg, 18.2 : 1 on surface

  • --color-bg
    #eef1f3 · page background (with --gradient-page)

  • --color-surface
    white 75 % · glass cards, fields (≈ #fbfcfc on bg)

  • --color-brand
    #111215 · pills, button, focus ring
    with --color-on-brand (#ffffff): 18.7 : 1

  • --color-brand-hover
    #33363c · button hover
    with on-brand: 12.1 : 1

  • --gradient-shimmer (accent)
    pink → peach → lavender · highlight card
    text on it: at least 10.3 : 1

  • --color-text-muted
    #5d646e · dates, captions, footer
    5.3 : 1 on bg, 5.8 : 1 on surface

  • --color-field-border
    #7b828c · form field edges
    3.4 : 1 on bg (UI part, needs 3 : 1)

  • --color-line
    #dde3e8 · decorative lines only
    1.1 : 1, never for text or controls

Muted text is too light on the shimmer gradient (only 3.3 : 1 on lavender), so inside the highlight card dates use --color-text.

Typography

Font: system-ui (San Francisco on Mac, Segoe UI on Windows). No font file to download and no request to a third party, so the page is fast and private, and every system shows a font made for its screen.

Heading 1 · --font-size-h1

clamp(2.25rem, 1.5rem + 4vw, 3.5rem): fluid between phone and desktop

Heading 2 · --font-size-h2

clamp(1.5rem, 1.2rem + 1.5vw, 2rem)

Heading 3 · --font-size-h3

1.25rem

Body text · --font-size-body 1rem, line height 1.6, at most 65ch per line. A link is underlined in the text colour and turns muted on hover.

Spacing

Only these values are used for margins, paddings and gaps.

--space-1 0.25rem

--space-2 0.5rem

--space-3 1rem

--space-4 1.5rem

--space-5 2rem

--space-6 3rem

Other sizes: radius pill 999px, card 1.5rem, field 0.75rem; border 1px; focus ring 3px; glass blur 12px; touch target at least 24px (WCAG 2.5.8).

Components

Button

Black pill. The first button is live: hover it, or press Tab to see the focus ring. The others show each state fixed.

Hover: lighter black. Focus: 3px black outline with a gap (:focus-visible, only for keyboard). Disabled: grey with muted text (4.6 : 1) and a not-allowed cursor.

Card

Glass card

November 2026

White 75 % surface, white edge, soft shadow and a blur of the background. Used for news and the picture.

    November 2026

    The same card with the shimmer gradient: only once per page, for the newest item.

Navigation pill

  • Current page
  • Other page

The current page (aria-current="page") is a black pill, so it is shown by shape and colour, and screen readers announce it.

Form field

Radio buttons

Label above the field, field edge 3.4 : 1 (WCAG 1.4.11), darker edge on hover, same focus ring as the button, radios in the brand colour.

Breakpoints

Mobile first: one column by default, then two layout changes. In rem, so they move with the user's font size and still work at 400 % zoom. Written directly in the media queries, because custom properties don't work in media query conditions.
